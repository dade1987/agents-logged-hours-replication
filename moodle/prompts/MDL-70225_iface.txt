Issue MDL-70225: Enhance Simple Global Search to match start of words instead of relying on exact terms

The current implementation of Simple Search is a little too simple. We should look at partial word matching to yield results that are more inline with common search behaviour.

h3. *Current limited search example*

# Set up [Simple Search|https://docs.moodle.org/502/en/Global_search] engine for Global Search
# Create course with name _Course CU99999_
# Create course with name _Course CU99999V20_
# Perform course search using CU99999
# Notice that only one course is found (we would expect two results)

h3. *Performance considerations*

* It may be too expensive to search for any and all substrings (e.g. searching for ‘our’ would match ‘course’). 
* Simple search matches against all courses and modules within a course, so we have to be careful we don’t affect performance too negatively.
* Search is performed against indexed content {{php search/cli/indexer.php}}

h3. *Documentation*

The [current documentation for Simple Search|https://docs.moodle.org/502/en/Global_search] will need some updating when this improvement lands.

h3. *Expected search results*

# Courses
## Cats 101
## Dogs 101

* Searching for ‘*101*’ returns ‘*Cats 101*’ and ‘*Dogs 101*’
* Searching for ‘*Cats Dogs*’ returns nothing (should match with AND)
* Searching for ‘*Cat 10*’ returns ‘*Cats 101*’
* Searching for ‘*Dog*’ will return ‘*Dogs 101*’
* Searching for ‘*ogs*’ returns nothing (unless we can determine this won’t affect performance too negatively)
