Issue MDL-89960: Marking workflows feedback shows markers names on feedback when grader identity hidden and some feedback from un-allocated markers

When marker names were added to the individual feedback comments on assignments with multiple markers, it did not factor in the {{Hide grader identity from students}} setting, so although the “Graded by” section is still correctly hidden on the student’s view, individual feedback comments still list the graders' names alongside their comments.

!MDL-89960-unpatched.png|width=716,alt="MDL-89960-unpatched.png"!

The same applies to feedback annotated PDFs and feedback attached files. All 3 places need to hide the marker name, *unless* the user has the capability to view hidden graders.

Additionally, we should only be sharing all of this feedback with the student for markers who are allocated to the submission. Currently if someone leaves a feedback comment or attachment, they are being shown to the student even if they have been unallocated (eg they were replaced by another marker), which should not be the case because they are not an active marker (and those records are simply retained in the database to avoid dataloss). This does not affect annotations, which already check and include just the currently assigned markers.
