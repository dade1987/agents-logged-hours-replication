Issue MDL-88924: New mobile app authentication setting to enable "Deep-linking with auto-login"

h3. Summary

Add a new mobile app authentication setting to explicitly enable “Deep-linking with auto-login”.

h3. Context

It is currently possible to generate deep links with auto-login by passing the user WS tokens in the link. This is not recommended in some scenarios. It should be explicitly allowed by an admin setting.

Reference:
[https://moodledev.io/general/app/development/link-handling/deep-linking|https://moodledev.io/general/app/development/link-handling/deep-linking|smart-link]

h3. Acceptance criteria

* Add a new setting in:
** Site administration > Mobile app > Mobile authentication
* Setting details:
** Name: Enable auto-login in deep links
** Setting key: tool_mobile_enabledeeplinkautologin
** Default value: Unchecked
* Description for the setting:
** By enabling this option, users will be automatically logged in to their site in the mobile app via a deep link when the token and privatetoken are passed as parameters in the deep link.
* The tool_mobile_get_public_config Web Service should return the previous setting always, regardless of its value.
* The mobile app will check whether auto-login is enabled via deep-links by checking the previous setting.

h3. Other information

* Deep links can currently be generated with auto-login by passing the user WS tokens in the link.
