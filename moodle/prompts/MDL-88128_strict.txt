Issue MDL-88128: Moodle doesn't match Accept-Language if not exact when setting the lang for a new session

Found while triaging [https://moodle.atlassian.net/browse/MDL-88104|https://moodle.atlassian.net/browse/MDL-88104|smart-link], Moodle should follow normal best practice and try to match up any installed language packs with the users language preferences sent via the Accept-Language header.

There is code for this but it doesn’t seem to always work, and I think the real bug is it must exactly match the lang packs. For example if you set chrome location to Tokyo then it sets a header of {{accept-language: ja-JP}} but the language pack installed is just {{ja}} so it doesn’t select.
