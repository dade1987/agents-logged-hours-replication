Issue MDL-61427: Add option to delete questions when deleting a question category

*How it works now*

When deleting a question bank category you are forced to save all questions in this category to another category. Questions then may be deleted either separately or in bulk (improvment added in Moodle 4.x versions).

*Expected behaviour*

It would be nice if the questions in a category would be deleted if the category is deleted. Or, if this is considered inconvenient or unsafe for some reason, if one had the possibility to choose whether a) the category including questions will be deleted or b) category including questions will be deleted.

Of course, questions that are used in quizzes (usually marked with an asterisk) should always be saved to another category. In order to have a rather simple procedure, the solution might be that it is only possible to delete a category including questions if none of the questions is used in a quiz.

*Usecase*

One might ask why deleting categories is important. Here is why: Many of our lecturers export older quizzes from one course to a new course. Along with the quizzes come the question banks. Some of the categories and questions are used in the new course, some not. In order to keep the question bank in the new course lucid, categories an questions that are not relevant are deleted. This process would be much faster if categories and questions could be deleted at the same time.
