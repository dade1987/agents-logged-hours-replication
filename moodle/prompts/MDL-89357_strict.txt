Issue MDL-89357: Use late static binding in AI actions base class

Issue creation assisted by Github Copilot.

h2. What

Replace all `self::` references in `core_ai\aiactions\base` with `static::` so that child classes can properly override static methods (particularly the new `get_features()` and `get_privacy_class()` methods).

h2. Why

PHP's `self::` keyword refers to the class where the method is defined, preventing child classes from overriding static methods in the base class. Without it, calls to `base::get_features()` would always use the base implementation, ignoring child overrides.

h2. What to implement

* Audit all `self::` usages in `core_ai\aiactions\base`.

* Replace `self::` with `static::` for any static method call that child classes are expected to override.

* Ensure no behavioural regressions in existing action classes (`summarise_text`, `explain_text`, `generate_text`, `generate_image`).

* Add or update unit tests verifying that child class static method overrides are correctly invoked when called from base class context.

h2. Acceptance criteria

* All static method calls in `core_ai\aiactions\base` that are designed for override use `static::` instead of `self::`.
