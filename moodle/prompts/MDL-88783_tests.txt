Issue MDL-88783: enrolcoursewelcomemessage uses profile URL as context URL instead of enrolled course URL

When sending the enrolcoursewelcomemessage message from enrollib.php:3728, the message context URL points to the user profile page, but this is a course welcome notification and should link to the enrolled course page.

h4. Current behavior

* contexturl is set to the user profile URL:
** /user/view.php?id=<userid>&course=<courseid>

h4. Expected behavior

* contexturl should point to the course URL where the user was enrolled:
** /course/view.php?id=<courseid>

h4. Affected location

* enrollib.php:3728
* Method: enrol_plugin::send_course_welcome_message_to_user()
* Message name: enrolcoursewelcomemessage

h4. Impact

Users who receive the welcome notification are sent to a profile context instead of the target course, which is confusing and adds friction to first access after enrolment.
