Issue MDL-89711: Quiz: get_effective_open_close_times() renamed without deprecation, breaking public API

As part of [https://moodle.atlassian.net/browse/MDL-82521|https://moodle.atlassian.net/browse/MDL-82521|smart-link], override_manager::get_effective_open_close_times() was renamed to get_effective_times() with no backwards-compatible shim.

get_effective_open_close_times() is a public static method that shipped in Moodle 5.2. Renaming/removing a released public API method without going through Moodle's deprecation process breaks any code (plugins, or other core callers) that still calls the old name.

Steps to reproduce:

# Call mod_quiz\local\override_manager::get_effective_open_close_times($quizid, $userid) on a site running the version that includes the [https://moodle.atlassian.net/browse/MDL-82521|https://moodle.atlassian.net/browse/MDL-82521|smart-link] patch.
# Observe a fatal error: Call to undefined method.

Expected: The Moodle 5.2 public method get_effective_open_close_times() should continue to exist and work (e.g. by delegating to get_effective_times()), and be marked and processed via the standard staged deprecation flow, rather than being removed outright.

Suggested fix:

* Re-add get_effective_open_close_times() as a wrapper that calls get_effective_times() and returns only the timeopen/timeclose keys (to preserve its original return contract), marked @deprecated since Moodle x.x, with an entry added to mod/quiz/deprecatedlib.php per the deprecation guidelines.
