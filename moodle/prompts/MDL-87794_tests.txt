Issue MDL-87794: Formula Escaping brakes CSV import

Given is  the following file user.csv

{noformat}lastname;firstname;username;email;password
Testy;Testx;test25@example.com;test25@example.com;@ChangeMe!{noformat}

When the file is uploaded in “Site administration” → “Users” → “Upload users” the password gets prefixed with a single quote.

That is because of the change in MDL-72744 (see also this post: [https://moodle.org/mod/forum/discuss.php?d=471301|https://moodle.org/mod/forum/discuss.php?d=471301]).

While I do understand the necessity of the fix, when writing spreadsheet files for the user to download,  here we have an import/upload of CSV data, where formulas have no effect. IMHO there should be distinguished between uploads without escaping and download where formulas should be escaped.
